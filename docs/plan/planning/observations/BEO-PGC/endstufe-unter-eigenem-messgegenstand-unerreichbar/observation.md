# BEO-PGC/endstufe-unter-eigenem-messgegenstand-unerreichbar

**Sub-Area:** `*`/`PGC` (Repo-weite Default-Sub-Area — betrifft das Verhältnis
zwischen einer zugesagten Zielzahl und dem Messgegenstand, der sie belegen soll,
keine eigene Sub-Area im Sinn der Modus-Deklaration).

Die Beobachtung: Ein Gate oder eine Entscheidung nennt eine **Zielzahl**
(Endstufe, Schwellenwert, Quote), während der eigene **Messgegenstand** sie
strukturell nicht erreichen kann — ausgeschlossene Pakete, übersprungene Tests,
ein Umfang, der den Gegenstand nicht deckt. Die Zahl ist dann keine Zusage,
sondern eine Absichtserklärung: sie sieht erreichbar aus, ist es aber nie, und
jede Fortschrittsmeldung gegen sie ist von vornherein gedeckelt. Belegt an
`ADR-0054` §(a): Endstufe 80 %, Messumfang ohne die netzlos nicht laufenden
DB-Adapter-Pakete → Decke 68,06 %. Behebbar nur durch eine Entscheidung über den
**Gegenstand** (`ADR-0071`), nicht durch mehr Arbeit an der Zahl.
