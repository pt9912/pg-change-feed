# BEO-PGC/roadmap-kontext-verwaist-nach-zeilen-entfernung

**Sub-Area:** Planning-Harness / Roadmap (Sub-Area-Kürzel `PGC` aus der
Modus-Deklaration)

Die Beobachtung: `docs/plan/planning/in-progress/roadmap.md`s
„Nächste Wellen"-Abschnitt trägt gelegentlich erklärenden Prosa-Text
oberhalb mehrerer Tabellenzeilen (z. B. „E2E-Abdeckungsprogramm ...
vier Wellen"), der den Kontext/die Herkunft dieser Zeilen-Gruppe erklärt.
Beim Entfernen einer einzelnen Zeile aus einer solchen Gruppe (Umplanung,
Re-Scoping) wurde der darüberstehende Gruppen-Header nicht mitgeprüft —
er blieb stehen, obwohl er sich (teilweise oder vollständig) auf die
entfernte Zeile bezog, und hing danach fälschlich über den verbleibenden,
inhaltlich unabhängigen Zeilen. Der Fehler wurde nicht durch einen Sensor
gefunden, sondern durch eine direkte Nutzerfrage („warum steht das in
roadmap.md?").
