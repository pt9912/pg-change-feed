**Vorgang:** slice-backfill-sql-administration (Review F-10, Behebung durch Verifikation M-F10 nachgemessen)

**Fund:** Die Annahme „je Quelle nimmt eine Instanz Anträge an" (`ADR-0113` Festlegung 1) hing an einer Queue-Lesung ohne Quellfilter: `SelectPendingAdministrationRequests` liest alle offenen Anträge (`WHERE status = 'pending'`), die Administrations-Goroutine verglich `request.Source` nicht mit der Quelle ihres Containers, der Worker liest dagegen nur `Queued(deps.source)`. Bei mehreren Containern verschiedener Quellen gegen eine Datenbank konnte ein `backfill`-Antrag der Quelle B von Instanz A gegen deren Publication geprüft, mit `failed` beendet oder als Run für B angenommen werden, ohne dass der Worker von B geweckt wird; kein Test band die Annahme. Umgesetzt für die Antragsart `backfill`: `processAdministrationRequests` übergeht einen Antrag einer anderen Quelle (er bleibt `pending` für die Instanz seiner Quelle), Unit-Test mit zwei Quellen und Login-Test mit einem Antrag einer fremden Quelle; der Verifier sah die Mutation (Vergleich entfernt) rot. Benannte Rest-Grenze: die vier übrigen Antragsarten lesen weiter alle offenen Anträge ohne Quellbezug (Bestand aus `ADR-0050`), und zwei Instanzen derselben Quelle bleiben ohne Schutz (Gegenstand des Erstbelegs).
