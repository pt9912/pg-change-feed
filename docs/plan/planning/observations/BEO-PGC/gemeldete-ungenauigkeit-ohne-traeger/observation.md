# BEO-PGC/gemeldete-ungenauigkeit-ohne-traeger

**Sub-Area:** `*`/`PGC` (Repo-weite Default-Sub-Area — betrifft die Übergabe einer
Meldung aus einer Slice-Closure, keine eigene Sub-Area im Sinn der
Modus-Deklaration).

Die Beobachtung: Eine Closure-Notiz nennt eine Ungenauigkeit in einer Code- oder
Schema-Datei „gemeldet“ oder „ohne Träger-Slice“ — der Slice ändert die Datei nicht,
weil sie außerhalb seines Zuschnitts liegt oder ein Werkzeug verlangt, das dieser
Slice nicht fährt. Die Meldung ist das Übergabe-Artefakt (`AGENTS.md` §3.13), sie
braucht aber einen **Empfänger**: ohne Folge-Slice-Zeile, Register-Eintrag oder Zeile
der Results-Notiz steht die Ungenauigkeit unverändert im Baum, und niemand ist
zuständig. Der Closure-Note-Review der Welle findet sie als Lücke im Folgeschritt
(Inhaltspflicht (b): zugesagter Folgeschritt ohne Träger).

**Abgrenzung.** `BEO-PGC/arbeit-ueberholt-stehenden-traeger` beschreibt einen
Träger, den eine Arbeit falsch macht und den der Suchlauf finden soll; hier ist der
Träger **gefunden und benannt**, es fehlt die Adresse der Korrektur.
